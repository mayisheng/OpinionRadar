# 路线图

迭代顺序原则：**先纵向打通一条最窄的链路，再横向补内容类型，再提质量，最后扩平台**。

| 迭代 | 主题 | 主要范围 | 退出标准（可验证） |
|---|---|---|---|
| 000 ✅ | 地基 | 分层骨架、工具链、CI、文档体系、launchd 模板 | lint/test 全绿；`doctor`、`run --dry-run` 可用；按本计划落库 |
| 001 | MVP 跑通 | 单博主视频增量采集 → 字幕（兜底 Whisper）→ Qwen3 摘要 → Server酱推送 → 每小时调度 | 发一条新视频后 1 小时内手机收到摘要；重复运行不产生重复推送 |
| 002 | 图文与付费 | 专栏、图文动态、充电专属（Cookie）、RapidOCR | 三类图文内容均能入库并产出摘要；无 Cookie 时优雅降级 |
| 003 | 观点结构化 | 标的/方向/逻辑/依据/风险/时间点 JSON 抽取；跨内容去重归并；Prompt 版本化 | 10 条历史内容样例上抽取字段齐全率 ≥90%；同标的重复观点合并展示 |
| 004 | 日报与体验 | 每日 digest、多博主配置、推送模板、质量标记 | 每天 20:00 收到一条聚合日报；可标记推送质量；支持 ≥3 博主 |
| 005 | 健壮性 | 风控退避/中止、失败告警推送、运行统计、云端模型兜底开关 | 断网/Ollama 挂/风控三种故障均能自愈或告警；连续 7 天无人干预运行 |
| 006 | 多平台 | 新增一个平台 Connector（公众号/雪球/微博择优） | 新平台内容与 B站内容共用同一管线产出推送，核心层零改动 |

## 依赖关系

```text
000 ─→ 001 ─→ 002 ─→ 003 ─→ 004
                   └→ 005（可与 004 并行择期）
003/004 完成后 ─→ 006（用真实扩展检验 Connector 抽象）
```

## 暂不入路线图（Backlog 候选项）

- Bark / Telegram / 飞书等推送渠道（Notifier 接口已预留，需要时随时插入，不占整迭代）
- Web 本地面板查看历史观点（等内容沉淀足够多后再评估价值）
- 观点准确率的自动评测集（迭代 003 手工评测，规模化后再考虑）
