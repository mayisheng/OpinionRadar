# 迭代 001：MVP —— 跑通「视频 → 摘要 → 微信推送」一条链路

- 状态：Planned
- 日期：待定（建议迭代启动后一周内）
- 关联 Issue：启动时创建并回填（#feat: 视频增量采集 / 字幕转写 / LLM 摘要 / Server酱 / 建表）

## 目标

发布一条真实的博主新视频后，1 小时内手机收到一条含摘要与原文链接的微信推送；
连续执行不重复推送、不漏播。

## 范围

> 采集路线已变更：由 httpx + wbi 直连改为 Playwright 真实浏览器响应拦截（ADR-0005）。
> 本迭代分两段交付：**第一段先跑通空间动态流（图文 + 视频）增量发现**，
> 浏览器链路与风控基线稳定后，再接入字幕、存储、分析、推送完成端到端 MVP。

**In：**

- 采集（第一段，先行）：Playwright 持久化 profile + 有头扫码登录；
  打开空间动态页，人类节奏滚动，拦截 `feed/space` 响应，产出图文/视频 `ContentItem`；
  风控熔断（验证码 / -352 / 登录态失效立即中止冷却）
- 采集（第二段）：视频播放页拦截字幕地址；无字幕时 yt-dlp 取音频 + mlx-whisper 转写（单并发）
- 存储：SQLAlchemy 模型 + 首个 Alembic 迁移（sources / content_items / summaries / push_logs），
  `platform + external_id` 幂等，状态机 `discovered → pushed`
- 分析：Ollama OpenAI 接口调用 Qwen3-14B，`analyze_v1.txt` Prompt，
  产出 `category + tldr`（观点结构化只做透传，不强求质量）
- 推送：Server酱 `send` 实现，单条 Markdown 即时推送 + push_logs 幂等
- 调度：`make launchd-install` 后每小时 `opinion-radar run` 真实运行
- 运维：`doctor` 增补数据库/密钥检查；runbook 记录首周观察项、登录与熔断排查

**Out（推到后续迭代）：**

- 评论区博主回复抓取（主楼 + 楼中楼按 mid 过滤，拼入正文；动态流稳定后的下一阶段）
- 专栏、充电/付费内容（→ 002）
- 图片 OCR（→ 002）
- 观点字段精细化与跨内容去重（→ 003）
- 每日 digest（→ 004）
- PushPlus/Bark 等其他渠道、失败告警、云端兜底（→ 005）

## 任务拆解（按层，开发顺序即依赖顺序）

1. **collectors / 第一段（当前）**：Playwright 会话（持久化 profile、登录命令、
   人类节奏、风控熔断）→ 空间动态流拦截与分页 → 纯解析器产出 `ContentItem`
   （图文 / 视频 / 转发）→ fixtures 单测 + `discover` 探测命令真实验证
2. **storage**：ORM 模型 + Alembic 初始化 + 仓库读写与状态推进（含单元测试）
3. **extractors**：播放页字幕拦截提取器 → 音频下载 + mlx-whisper 回退链
4. **analysis**：OpenAI 客户端封装 → analyze_v1 Prompt → JSON 解析与 schema 重试
5. **notifiers**：Server酱 send + 响应解析 + 重试
6. **pipeline**：五阶段编排、单条失败隔离、last_seen 推进、日志
7. **deploy**：launchd plist 实跑验证；首周日志观察

## 验收标准

- [ ] 全新数据库执行迁移后，对有历史视频的博主首轮运行，行为正确（历史视频策略：仅处理最近 N 条/最近 7 天，配置化，避免首轮轰炸）
- [ ] 博主发布一条新视频后，下一轮 run 产出推送：标题为分类+tldr，正文含摘要与原文 URL
- [ ] 视频有字幕时不触发音频下载；无字幕视频能完成转写（人工选 1 条短视频真测）
- [ ] 连续执行 3 次 `run`：同一视频只推送 1 次（push_logs 幂等可验证）
- [ ] Ollama 停止时 run 不崩溃：内容状态保持可重试，错误入日志
- [ ] launchd 加载后，`launchctl print` 可见任务；手动 kickstart 能跑通；日志落在 data/logs
- [ ] `make lint && make test` 绿；关键外部边界均有 mock 测试；CHANGELOG 更新为 0.2.0
- [ ] 手机实际收到推送且排版可读（自己验收，截图留迭代文档）

## 风险与对策

| 风险 | 对策 |
|---|---|
| B站接口签名/风控变化 | fixtures 对拍；风控响应立即中止本轮；失效 2 次内触发 ADR-0003 的换库评估 |
| 14B 模型摘要慢/质量不稳 | 先跑通；对超长转写文本截断+ map-reduce 留待 003；允许配置临时切 qwen3:8b 对比 |
| Whisper 首轮下载/转写耗时长 | 字幕优先；首轮只处理最近 N 条；转写单并发并记录耗时日志 |
| launchd 下 PATH/环境与交互 shell 不同 | plist 显式声明 PATH 与工作目录，安装脚本做 `plutil -lint`，runbook 给排查命令 |
