# 产品需求文档（PRD）

- 版本：v0.1（迭代 000 建立，随迭代更新）
- 一句话定义：**把 B 站财经博主分散的付费图文、视频、行情观点，定时变成手机上一份结构化的观点摘要。**

## 1. 背景与问题

- 关注的财经博主持续产出视频、专栏、图文动态、充电专属内容，**信息分散在多种内容形态里**。
- 视频动辄二三十分钟，图文付费后也难以及时看完；行情观点有时效性，「刷到时已经错过」。
- 博主的判断散落在各期内容中，缺少**按标的/方向聚合的连续视图**。

## 2. 目标用户

本人（个人使用）：有一定财经信息获取习惯，希望用本地自动化 + LLM 帮自己做信息初筛，
**不接受**付费内容与账号 Cookie 离开本机。

## 3. 目标与非目标

### 目标

1. 定时、增量地拿到博主的新内容（视频/图文/动态/付费），不漏不重。
2. 视频内容自动转文字，图文内容自动抽正文、图片观点自动 OCR。
3. 本地模型完成：内容识别分类、一句话摘要、结构化观点（标的/方向/逻辑/依据/风险/时间点）。
4. 结果即时推送到微信；每天再给一条聚合日报。
5. 单机无人值守稳定运行，失败可自愈或至少有告警。

### 非目标（明确不做）

- 不输出**买卖建议**、不做自动交易、不做收益回测；摘要只转述博主观点并标注来源。
- 不做多用户、Web 界面、公网服务。
- 不搬运、不二次发布任何付费内容；推送内容仅为个人学习摘要。
- 不做全网舆情监控（首期单人单平台，多平台是后期可选项）。

## 5. 推送消息形态（示例）

```text
【行情点评】某博主：对后市维持谨慎，等待量能确认
摘要：认为短期指数上行空间有限，关注三季度盈利验证……
观点：
· 沪深300 / 中性偏空 / 等待放量信号 / 风险：外盘波动
原文：https://www.bilibili.com/video/BVxxxx
（qwen3:14b 摘要，仅供学习参考）
```

## 6. 非功能需求

- **频率克制**：单博主请求间隔 ≥6 秒 + 随机抖动；每轮总量有上限；遇到风控立即休眠。
- **隐私**：Cookie/Key/原文不出本机；LLM 默认本地推理；`data/` 全目录可直接备份/删除。
- **资源**：转写单并发；内存峰值可接受（32GB 机型跑 14B 模型 + 转写）；
  单轮 `run` 目标 < 调度间隔（1 小时）。
- **可观测**：本地轮转日志；关键失败在迭代 005 后可主动推送告警。

## 7. 成功度量（每个迭代复盘时看）

- 增量采集零漏抓（以手动检查博主主页为基准）。
- 推送的摘要「打开率/有用率」主观评价（自己标记无用推送，迭代 004 支持回看标记）。
- 单周人工阅读/刷找时间明显下降；无用推送率逐迭代下降。

## 8. 合规边界

本项目仅处理本人账号有权访问的内容，输出为帮助理解的摘要，版权归原作者所有；
不存储/传播付费原文，不用于商业用途，并遵守平台用户协议与 robots/风控约束。
